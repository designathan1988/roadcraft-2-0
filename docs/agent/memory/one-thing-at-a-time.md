Work on one problem until it is solved. Whatever else turns up on the way (a defect, a cleanup, an idea) is written into `docs/agent/BACKLOG.md` with where it is and the evidence, and is not touched until the task in hand is finished.

**Why:** on 2026-10-27, while hunting the camera's slowness, I switched to fixing the far buildings' night lights I had noticed; the owner: "PARE DE FICAR MISTURANDO AS COISAS. CORRIJA UMA COISA DE CADA VEZ ... REGISTRE EM UM ARQUIVO DE LISTA PARA RESOLVER DEPOIS".

**How to apply:** before switching subject, ask whether it is the task in hand; if not, add a BACKLOG entry and go back. Take the next BACKLOG item only after the current task is done and reported.
